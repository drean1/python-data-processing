# Python Data Processing

A personal project to practice Python data processing and report automation using Polars, DataFrames, and CSV files.

## Overview

This repository contains Python scripts and exercises for learning data manipulation, CSV processing, and basic report generation.

## Features

- Reading and processing CSV files
- Working with DataFrames using Polars
- Basic Python programming exercises
- Processing sales data and generating reports
- Practicing data transformation and aggregation

## Technologies

- Python
- Polars
- CSV

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/drean1/python-data-processing.git
cd python-data-processing
```

### 2. Create a virtual environment

```bash
python3 -m venv env
```

### 3. Activate the environment

For macOS and Linux:

```bash
source env/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the sales report script

```bash
python sales_report.py
```
